# Islamic Smart Prayer Box

Project Description
It is a Raspberry Pi-based smart prayer box designed to:
Show the current prayer time
Play Adhan in Bangla mosque style
Move a servo to open a flap
Turn on LED lights during prayer


purpose
This project was created to help remind me and other users to prayer on time even when offline

3D Case:
Case dimensions: 24.716cm × 10.652cm × 10.198cm      409.36 cm³

1. Insert the SD card into the Raspberry Pi and connect power.
2. Run the firmware
3. Configure prayer times 
4. The box will automatically:
Play Adhan at prayer times
Move the servo flap
Turn on LEDs
